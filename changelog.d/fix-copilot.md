### Fixed

- A GitHub account with no Copilot plan no longer shows as "sign-in required". The Copilot row says that the account is signed in but has no plan, links to the Copilot page in your GitHub settings, and Try again checks it again. A chain of fallback models skips Copilot.
- A provider that no chat uses no longer shows an error message when Hive starts. The failure stays on its row in Settings.
